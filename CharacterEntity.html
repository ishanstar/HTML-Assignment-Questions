HTML Character Entities

Character Entity Purpose
© &copy; Copyright symbol
< &lt; Less-than sign
> &gt; Greater-than sign
" &quot; Quotation mark
± &plusmn; Plus or minus
× &times; Multiplication symbol
÷ &divide; Division symbol
€ &euro; Euro currency symbol

Character entities are useful when a character has a special meaning in HTML or when special symbols need to be displayed correctly.
